# V15 Sound Studio (incremental V14 upgrade)

## Install
Use the V15 update ZIP from the project root after stopping the server and backing up local modifications. `unzip -o ~/Downloads/m4-v15-sound-update.zip`, activate `.venv`, then `bash start.sh`. Full archive is also available. No new runtime packages or model downloads are required for basic sound analysis: FFmpeg, FFprobe, NumPy (already used by OpenCV/MLX), existing local models. Your OAuth configuration and existing clips remain outside this update. V14 incremental/quick replay defaults and strict 70/30 gaming layout are unchanged.

## Audio library
1. Visit https://www.youtube.com/audiolibrary and download tracks using the official UI. For both YouTube and Instagram, choose original or separately licensed cross-platform music/effects. YouTube's own documentation does not establish rights outside YouTube: https://support.google.com/youtube/answer/3376882 . The app conservatively restricts `youtube_audio_library` assets to YouTube. For a CC BY asset check the actual license, authorized rights and credit; no license is inferred from a track title, URL, or the file itself.
2. Put the audio files into a folder, e.g. `~/Music/ShortsAudio`. Next to each audio file create a UTF-8 JSON sidecar, with the **full audio filename plus `.json`**, e.g. `track.mp3.json`. `audio-license-example.json` is a template for your own original audio, not a license certificate or a supplied track. Replace all illustrative values and review the license yourself. For Audio Library standard tracks use `license: "youtube_audio_library"`, official source URL, `platforms: ["youtube"]`. For CC BY use `license: "cc_by"` and copy exact credit into `attribution`. For other separately licensed audio use `commercial_permission` and describe the authorization. Do not set `rights_confirmed: true` before reviewing the actual evidence. For music provide `vocals` and one or more supported moods; for effects set `kind: "sfx"`, `category` (e.g. `comedic impact`, `cinematic impact`, `victory`, `whoosh`, `pop`, `dramatic reveal`, `record scratch`). Unknown or incomplete licenses are rejected. `genre`, `instruments` may be entered by the user. No vocal or instrument classifier is installed.
3. Use **Viral AI editor → AI sound studio & reference style → Import / refresh audio folder** or run:
   ```bash
   python sound_studio.py import "$HOME/Music/ShortsAudio"
   python sound_studio.py list
   ```
   Re-importing unchanged files reuses cached analysis. Library assets and metadata are copied to `~/.config/m4-shorts-studio/sound-library/`. The importer analyzes at most the first 600 seconds of a track (estimated beat grid, onsets, RMS energy, waveform, source file hash). Only that analyzed portion can be selected. Assets are checked against stored content hashes. Import/refresh is explicit, not a continuous folder watcher. Remove a revoked asset's corresponding hash-named metadata JSON from this directory; existing mixes with unavailable assets are blocked from automatic/manual publishing. Keep the original license evidence separately.
4. Enable **Automatically select licensed music and effects**. For YouTube-only projects, opt into the YouTube-only rights setting. With Instagram automatic publishing selected the app always requires portable assets; default local/manual projects also require both platforms. If a YouTube-only mix is later manually published to Instagram, the backend refuses it. Required credit is appended by the publishing backends even when the description is manually edited. Existing explicit `SHORTS_AUTHORIZED_MUSIC` / `SHORTS_AUTHORIZED_SFX` legacy environment variables still work when automatic audio is off; they remain a user rights responsibility and do not receive the new license checks. Do not configure them for unlicensed or platform-restricted assets.

## Reference analysis
The requested URL https://youtube.com/shorts/7dlo2jQXK6s was not accessible for actual video inspection in the development environment. No analysis of its actual contents is claimed. Import an authorized local copy (1–180 seconds) in the sound studio or run:
```bash
python sound_studio.py reference "/path/to/authorized-reference.mp4" --authorized
# Optional existing Gemma vision model: adds snapshot observations, no reference assets copied
python sound_studio.py reference "/path/to/authorized-reference.mp4" --authorized --deep
```
Select the saved profile before generation. Reference pulse BPM is a weak ranking preference only when its confidence is adequate; mixed dialogue/music/FX cannot be separated by this analyzer. Scene-change candidates and mean interval are measured at 2 FPS; optional visual observations and caption suggestions are subjective estimates from eight snapshots, not verified animation/camera-motion detection. Choose your caption style explicitly. No reference footage/music/branding is inserted. Multiple profiles can be stored and selected individually, not combined into a learned model.

## Editing / rendering
- The existing AI selection request can return a music mood or `none` without another inference request. Existing story classification, measured energy, estimated BPM (with reference preference), duration and session-level recent track use rank reviewed instrumental assets. No suitable asset means original sound only. Music start can be shifted to align an estimated beat with an existing edited impact timestamp; the source dialogue and video timing are not moved. SFX are optional, selected by story and mood, one impact event per clip. Music fades, dialogue/stream-level sidechain ducking, optional brief pre-payoff dip, noise reduction, compression and one-pass loudness normalization are applied by the existing FFmpeg decoration pass. Default target -14 LUFS / -1.5 dBTP, not a mandatory platform standard. Set `SHORTS_MIX_LUFS` (-23 to -10) and `SHORTS_MIX_TRUE_PEAK` (-5 to -1) before starting the app to override. When adding tracks, a separate audio-only EBU R128 check records actual final integrated loudness and true peak; large deviations warn, clipping/extreme loudness is rejected. Source speech/game audio may already be mixed and cannot be independently adjusted; no source separation or independent ambient stem.
- `clips.json` retains the audio decisions, track fingerprint, platform permissions, impact, chosen segments, layout, hook/ending and caption style. Timed caption words are saved separately where available. The editor is an audio-focused review interface, not a fully editable multitrack NLE. New auto-audio clips keep a clean master even with captions off, increasing storage. In a saved clip expand **Audio director & editable mix** to select a track/no music, adjust music/effect gains, or toggle effects. Render after the session ends. The review mixes use the clean master audio and **copy the existing encoded final video** including captions; no new transcription, source download or video re-encode. Review copies are downloadable only, not automatically published. Original clip remains unchanged. The regular caption correction and alternate preview controls continue to work. If you manually upload a downloaded review copy, use its displayed credit and license permissions.
- CLI: add `--auto-music` to your normal viral command, optionally `--audio-youtube-only` and `--reference-style <profile SHA256>`. Do not set automatic Instagram publishing for a YouTube-only asset. Automatic audio is opt-in to protect existing quick workflow.

## Tests and limitations
Run `python -m unittest test_sound_studio -v` for actual audio analysis, cache and tamper checks, platform permission gates, beat alignment, real FFmpeg mix and byte-identical video stream, and local reference tests. `python -m unittest discover -v` runs previous and new tests. The synthetic fixture compares V14's original audio-only decoration and V15 mixing on the same 16-second vertical MP4. Timings vary with hardware. No full-stream M4 benchmark, real Ollama reference inference, public social upload or full browser interaction was run in this environment. No guaranteed Content ID clearance or automatic external license verification. No continuous watch folder, true audio source separation, complete style learning, automated semantic B-roll, new effects/animations, full drag-and-drop timeline, or automatic visual/music beat cut reordering in this release. No automatic upload of variants or remix reviews. Existing V14 `benchmark_pipeline.py` remains available for authorized 30/60/180-minute source comparisons.
